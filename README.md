# YouTube Downloader

## Описание
Программа скачивает аудио и видео дорожки с YouTube в любом выбранном качестве, используя модуль `yt_dlp`. Скрипт позволяет вручную выбирать ID форматов и объединяет их в один `.mkv` файл с помощью `ffmpeg`.

## Требования
1. **Python 3**: Должен быть установлен и добавлен в PATH.

## Использование
1. Запустите файл `yt_downloader.bat`. 
   Скрипт автоматически установит необходимые библиотеки (`yt-dlp`, `requests`), распакует и удалит архивы `ffmpeg` и `deno` и запустит основной скрипт.

2. Следуйте инструкциям программы:
   **Enter video URL**: Вставьте ссылку на видео.
   **Enter Video ID / Audio ID**: Введите выбранные номера из списков.

3. Готовый файл появится в папке `Downloads/` в корне проекта.
